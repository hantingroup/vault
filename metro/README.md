# 汉听大典/地铁

- 目录按“地理大区/省级行政区”分层，线路以城市为单位划分，一个城市一个文件，不按运营公司拆分（如北京、深圳、杭州均由多家公司运营，仍合并在城市文件中）。
- 台湾归华东，香港、澳门归华南。
- 仅收录已开通可乘坐的线路、车站；预留、规划但尚未建成的车站不收录。
- 除与国铁换乘站等站名本身以“站”字结尾的，站名不应包括“站”字后缀。
- 车站状态用后缀标记：

  - `‡`：车站已建成、但从未开办客运，如李冰广场‡、郫县东‡、新民场‡；
  - `†`：曾开办客运、现已停办的车站，含暂停待恢复的，如成都站†、犀浦东†、中川机场†；已停运的线路在同一位置给线名加，如张江有轨电车†。
  - 未标记的为正常运营。
- 环线未做特殊标记，与普通线路相同。
- 有支线的线路，以主线、支线为名直接记录；有两条以上支线的，支线按线名记录，如成灌线分为主线、离堆支线、成彭支线。
- 分段运营的线路：

  - 仅开通一段的，直接记录，如济南地铁6号线；
  - 已开通多段的，分开记录，如天津地铁4号线。
- 对于市郊铁路，除南京、温州称S1号线，其他城市均称S1线；国铁运营的市域（郊）铁路按线名收录，如上海金山铁路、北京S2线、城市副中心线、怀密线、通密线、天津津蓟线、成都成灌线（含离堆、成彭支线）与成蒲线、贵阳环城快铁、兰州中川城际、海口市郊列车、台州和合号、阳泉阳大铁路。
- 有轨电车线路一并收录，与地铁同列在城市文件中，线名用官方线路名（如大连201路、沈阳浑南有轨电车5号线），停运的线名加 `†`；胶轮导向有轨电车（Translohr，如上海张江有轨电车、天津开发区导轨电车）仍算有轨电车，云巴、智轨等无轨道约束的胶轮系统不收录。
- 只有有轨电车的城市另建文件，如淮安有轨电车、珠海有轨电车、三亚有轨电车、天水有轨电车、嘉兴有轨电车、黄石有轨电车、南平有轨电车、丽江轨道交通。
- 广佛线划归为佛山地铁1号线。
- 北京地铁八通线单独列出，与一号线无重叠车站。
- `杭海城际铁路.json` 与其他文件不同，根节点是 `Array` 而不是 `Object`。
- 港澳台单独说明：

  - 香港地铁收录港铁重铁线路及机场快线；香港轻铁、香港电车为多路线共用轨道运行的轻轨、电车网络，未收录。
  - 澳门轻轨各线独立列出，与主线共站的车站（如莲花、协和医院）各线分别记录。
  - 台湾部分按运营公司划分，同属台北都会区路网的台北捷运与新北捷运分开记录，环状线归新北捷运。
